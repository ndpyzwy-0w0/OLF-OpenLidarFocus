# OpenLidarFocus · DJI FM03

iPhone LiDAR 自动跟焦：Swift 功能层 + Flutter UI + ESP32-S3，经 CAN 收发器控制 DJI RS 跟焦电机（2022，FM03）。ESP32-S3 Super Mini 开发板和 72×40 OLED 保留。

原 TMC2209 / STEP / DIR / EN / UART / DIAG 控制已弃用。App 2.2.0+10 配合固件 2.0.5，UDP 协议版本 2。App 提供明确的新增标定点入口，支持在五点之后继续补点，并显示最近、最远标定距离。固件 OLED 开机完整显示 6 秒版本、热点名、密码和 IP，运行时显示可信位置/目标、实时 CAN/控制链路及寻限位/故障提示。2.0.2 / 固件 2.0.1 的链路修复保留：寻限位期间持续状态轮询、UDP 握手重试、忽略寻限位期间延迟到达的旧坐标回包；CAN 发送等待不持有电机状态锁，整包等待上限 50ms。所有输入框支持完成键、点外部和滚动收起键盘，键盘弹出时另有全局“收起键盘”按钮。

启动首页选择“自动跟焦”或“手机跟焦手轮”。自动模式沿用镜头、物距方向和至少五点标定流程；手轮模式不需要 LiDAR 或物距表，只需连接设备并完成 FM03 自动寻限位。

普通跟焦点击停止后锁定控制并禁用固件运动；滑条、手轮和迟到的目标包不能重新启动。按钮变为“复位继续跟焦”或“复位并继续手轮”。复位保留本次可信坐标和 A/B 点，不恢复旧手动目标；停止前处于自动模式时，需要新鲜 LiDAR 测距才能继续自动跟焦。内部自主寻限位仍无法软件中止。

手机手轮支持沿轮缘转动、刻度触感、0.25/0.5/1/2× 灵敏度、方向反转、拨轮最大速度、A/B 点设置/重设/清除、A/B 范围限制、端点直达及 0.5～8 秒目标过渡。A/B 点取停稳后的电机反馈，到位强触感由实际反馈确认；过渡时长不保证物理运动时间。重连、离开模式或重新寻限位后清除 A/B 点，切到后台自动停止锁定。

跟焦页顶部可点选切换横/竖屏。横屏以取景为主，右侧提供停止与自动/手动切换，底部显示电机状态与手动焦点滑条；右上角“控制与标定”打开完整面板，网格按钮开关构图辅助线。

## 接线与使用

接线、编译、刷写和验收见 [HANDOFF.md](HANDOFF.md)。CAN TX=GPIO4、RX=GPIO5，1 Mbps；OLED SDA=GPIO8、SCL=GPIO9 不变。

1. 给 FM03 独立供电，接好 3.3V CAN 收发器，与 ESP32 共地，断开 RS3。
2. 连接 ESP32 热点 `FF-XXXXXX`（密码 `change-me`），App 扫描、选用设备并连接。
3. 新建镜头，点击“FM03 自动寻限位”（横屏先打开“控制与标定”），等待阶段 1/2 → 3。FM03 内部维护两端限位，App 仅使用 0～4096 归一化坐标，不记录机械行程。
4. 用手机 + / − 按钮低速试转，结合相机画面选择物距变近的方向。
5. 用滑条或坐标增量手动对焦，画面实焦且电机停稳后点击“新增标定点”，记录物距和当前坐标。物距可手动输入，也可留空使用新鲜 LiDAR 测距。至少 5 点，覆盖近、中、远距离；达到五点后仍可继续新增。跟焦中点击“继续新增标定点”可退出自动跟焦并保留已有点位，继续手动实焦补点；物距相差不足 2 cm 时更新原点位。
6. App 按 1/物距分段插值生成图表，图表与跟焦使用同一映射。点击“开始跟焦”，有新鲜 LiDAR 距离后开启“自动跟焦”。有效测距小于最小标定物距时驱动到最近标定点，大于最大标定物距时驱动到最远标定点，不做外推；测距无效或过期时停止自动跟焦。
7. 方向和距离表自动持久化。重新连接、重启 App 或换镜头后先寻限位；已有表保留，不做最近点平移。更换齿轮安装位置或镜头后长按“重置距离标定”并确认，重新选方向和标定；改方向也会清空旧表。

坐标代表已校准镜头的归一化行程，不代表电机角度或 STEP 脉冲。新版使用 `lenses-fm03.json`，仅保存镜头信息、方向和距离表。2.0.0 的旧 FM03 表可能被对齐流程平移，升级时保留名称和备注、要求重新标定；旧 `lenses.json` 原样保留，不能沿用其步进标定数据。

FM03 参数：最大拨轮速度 1～256（默认 64）、到位容差 1～64（默认 4）、接近减速系数 1～64（默认 4）。这些是控制器参数，不是驱动电流或实际角速度。

内部校准暂无已验证的软件取消指令。“停止观察”只退出 App 观察流程；要立即中止内部校准须切断 FM03 电源。

flutter pub get
flutter analyze
flutter test
cd ios/FollowFocusCore && swift test
