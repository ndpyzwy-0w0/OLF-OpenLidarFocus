# OpenLidarFocus · DJI FM03

iPhone LiDAR 自动跟焦：Swift 功能层 + Flutter UI + ESP32-S3，经 CAN 收发器控制 DJI RS 跟焦电机（2022，FM03）。ESP32-S3 Super Mini 开发板和 72×40 OLED 保留。

原 TMC2209 / STEP / DIR / EN / UART / DIAG 控制已弃用。App 2.4.2+15 配合固件 2.1.1，UDP 协议版本 2。App 提供明确的新增标定点入口，支持在五点之后继续补点，并显示最近、最远标定距离。固件 OLED 开机完整显示 6 秒版本、热点名、密码和 IP，运行时显示可信位置/目标、实时 CAN/控制链路及寻限位/故障提示。2.0.2 / 固件 2.0.1 的链路修复保留：寻限位期间持续状态轮询、UDP 握手重试、忽略寻限位期间延迟到达的旧坐标回包；CAN 发送等待不持有电机状态锁，整包等待上限 50ms。所有输入框支持完成键、点外部和滚动收起键盘，键盘弹出时另有全局“收起键盘”按钮。

App 2.6.0+22 首页按设备状态、模式选择和使用指南重新布局，选择“自动跟焦”或“手动跟焦”。设备卡片区分未连接、正常连接和失去回包，可点击“管理”连接设备；两张模式卡片不再显示底部的 LiDAR／标定说明。整体字号调小，保留标题层级、系统大字体设置和按钮点击区域；所有页面的操作、状态、返回、展开与下拉图标统一使用 Lucide 图标库，提供深色和浅色外观，首页右上角可选择“跟随系统／浅色模式／深色模式”，iPhone保存选择并在下次启动时恢复。黑色取景覆盖层始终使用可读的深色主题，标定图表刻度与网格随外观调整。镜头库提供四步首次使用指南（寻限位、选择物距变近方向、确认对焦方向、至少五点标定），紧凑镜头卡片显示标定状态，并提供进入跟焦、添加镜头和菜单删除入口。自动模式沿用镜头、物距方向和至少五点标定流程；手轮模式只需连接设备并完成 FM03 自动寻限位。

普通跟焦点击停止后锁定控制并禁用固件运动；滑条、手轮和迟到的目标包不能重新启动。按钮变为“复位继续跟焦”或“复位并继续手轮”。复位保留本次可信坐标和 A/B 点，不恢复旧手动目标；停止前处于自动模式时，需要新鲜 LiDAR 测距才能继续自动跟焦。内部自主寻限位仍无法软件中止。

手机手轮固定在页面上，设置区单独滚动，停止按钮始终可见。整块手轮从按下起接管触摸，轮缘旋转、中心上下拖动微调，忽略第二根手指；支持刻度触感、0.25/0.5/1/2× 灵敏度和方向反转。电机速度直接显示在主界面，“手轮响应与设置”可调启动加速、接近目标减速及到位容差，显示误差/容差和设备已回读参数。固件2.1.1支持普通运动中调参，参数立即生效，回读确认，停稳后保存。手轮目标按20ms控制周期更新，无额外60ms限流。A/B 点支持设置/重设/清除、范围限制、端点直达及0.5～8秒定时拉焦，曲线可选缓入缓出或匀速目标。A/B 点取停稳后的电机反馈，到位强触感由实际反馈确认；过渡时长不保证物理运动时间。重连、离开模式或重新寻限位后清除 A/B 点，切到后台自动停止锁定。

跟焦页顶部可点选切换横/竖屏。横屏以取景为主，右侧提供停止与自动/手动切换，底部显示电机状态与手动焦点滑条；右上角“控制与标定”打开完整面板，网格按钮开关构图辅助线。

App2.4.2修复人脸识别方向与取景、LiDAR测距坐标不一致的问题：视频已经输出竖屏像素，Vision不再重复旋转；横屏识别结果先还原到竖屏视频/深度图坐标，再选择人脸、更新测距点和绘制识别框。实机验收时分别在竖屏和两个横屏方向左右、上下移动人脸，确认框与人脸同向且测距点随人脸移动。

App2.4.1在滑块轨道旁显示橙色A、蓝色B标记和位置百分比；标记在上下两侧，靠近时也可分辨，未设置时给出提示。App2.4.0在手机跟焦手轮页增加固定的“手轮／滑块”切换。滑块拖动按0～100%指定完整行程的绝对目标，立即接管A/B定时拉焦并遵循A/B限位；旋转灵敏度与方向反转只影响手轮。切换控件不发送新目标、不清除A/B点或重新寻限位。设置中可选标准刻度（60格／80ms）、密集轻触（120格／35ms）和清晰段落（30格／100ms），手轮按旋转圈数、滑块按全行程比例触发；时间为最小间隔，快速拖动不补发积压触感。两种输入共用触感开关和实际端点到位强触感，控制方式与触感选择保留在当前页面会话内。

## 接线与使用

接线、编译、刷写和验收见 [HANDOFF.md](HANDOFF.md)。CAN TX=GPIO4、RX=GPIO5，1 Mbps；OLED SDA=GPIO8、SCL=GPIO9 不变。

1. 给 FM03 独立供电，接好 3.3V CAN 收发器，与 ESP32 共地，断开 RS3。
2. 连接 ESP32 热点 `FF-XXXXXX`（密码 `change-me`），App 扫描、选用设备并连接。
3. 新建镜头，点击“FM03 自动寻限位”（横屏先打开“控制与标定”），等待阶段 1/2 → 3。FM03 内部维护两端限位，App 仅使用 0～4096 归一化坐标，不记录机械行程。
4. 用手机 + / − 按钮低速试转，结合相机画面选择物距变近的方向。
5. 用滑条或坐标增量手动对焦，画面实焦且电机停稳后点击“新增标定点”，记录物距和当前坐标。物距可手动输入，也可留空使用新鲜 LiDAR 测距。至少 5 点，覆盖近、中、远距离；达到五点后仍可继续新增。跟焦中点击“继续新增标定点”可退出自动跟焦并保留已有点位，继续手动实焦补点；物距相差不足 2 cm 时更新原点位。
6. App 按 1/物距分段插值生成图表，图表与跟焦使用同一映射。点击“开始跟焦”，有新鲜 LiDAR 距离后开启“自动跟焦”。有效测距小于最小标定物距时驱动到最近标定点，大于最大标定物距时驱动到最远标定点，不做外推；测距无效或过期时停止自动跟焦。
7. 方向和距离表自动持久化。重新连接、重启 App 或换镜头后先寻限位；已有表保留，不做最近点平移。更换齿轮安装位置或镜头后长按“重置距离标定”并确认，重新选方向和标定；改方向也会清空旧表。

坐标代表已校准镜头的归一化行程，不代表电机角度或 STEP 脉冲。新版使用 `lenses-fm03.json`，仅保存镜头信息、方向和距离表。2.0.0 的旧 FM03 表可能被对齐流程平移，升级时保留名称和备注、要求重新标定；旧 `lenses.json` 原样保留，不能沿用其步进标定数据。

FM03 参数：最大拨轮速度1～256（默认64）、到位容差1～64（默认4）、接近减速系数1～64（默认4）、启动加速1～64（默认8，每50ms增加的拨轮值）。固件2.1.1接近目标时输出为ceil(误差×速度/(64×减速系数))，再限制在速度上限内；速度64保持旧响应，其他值同时影响小幅追赶与上限；加速限制逐周期提高输出，换向先归零，停止/反馈失效立即归零。参数保存在设备NVS，连接时读取，不覆盖成默认速度；自动与手轮模式共用。数值不代表RPM或实际角速度。

响应慢可先将启动加速从8改到16或32、减速系数从4改到2，跟不上快速转动再提高速度上限。较高加速/较小减速系数可能增加机械冲击或来回修正，需用当前镜头实机确认。固件2.1.1可边转边调整，内部寻限位期间禁用调参。到位容差默认±4，个位数误差仍追焦时可试±8或±12，较大容差会降低到位精度。原“过渡时长”现称“A/B拉焦时长”，只影响“拉到A/B”的目标进度；默认缓入缓出为s(t)=3t²−2t³，匀速目标为s(t)=t。直接转手轮按旋转量线性更新目标，点“到A/B点”直接发终点。

启动加速调节需要固件2.1.0；运动中调参和追赶速度缩放需要固件2.1.1。App兼容旧固件的26字节反馈并禁用此项；新固件反馈扩展为28字节，必须配合新版App。构建不代表已安装或刷写。

内部校准暂无已验证的软件取消指令。“停止观察”只退出 App 观察流程；要立即中止内部校准须切断 FM03 电源。

```sh
flutter pub get

```

App2.3.1/固件2.1.1修复到位后的同目标心跳重新启动运动：容差内完成后保持静止；无进展失败保留目标且不重启，个位数抖动不再延长进展超时，App终止旧目标并允许下一次手轮从实际位置开始。状态区区分定时拉焦、追赶、确认到位和未到目标已停止。参数丢包250ms重试，2秒未确认会明确提示，不冒充调参成功。
